# stly

stly는 Structly의 Catalog를 조회하고 관리하는 Agentic CLI입니다. 이 공개 저장소는 외부 User에게 macOS 릴리스 파일을 배포합니다.

## 설치

[공개 Releases](https://github.com/structly-io/stly/releases)에서 설치할 버전의 다음 파일을 같은 디렉터리에 받으세요.

- Apple Silicon: `stly-darwin-arm64.tar.gz`
- Intel Mac: `stly-darwin-amd64.tar.gz`
- 체크섬: `checksums.txt`

체크섬 검증, 설치, 업데이트 방법은 [한국어 설치 가이드](https://docs.structly.io/ko/stly/install/) 또는 [English installation guide](https://docs.structly.io/en/stly/install/)를 따르세요. 명령 사용법은 설치 가이드에서 이어지는 사용자 문서와 [stly 명령 레퍼런스](https://docs.structly.io/ko/stly/reference/)에서 확인할 수 있습니다.

공개 파일은 Structly 제품 저장소에서 빌드한 기존 릴리스 산출물을 그대로 게시합니다. 아카이브에 포함된 README에는 접근 권한이 필요한 제품 저장소 링크가 남아 있을 수 있으므로, 외부 User는 위 공개 사용자 문서를 진입점으로 사용하세요.

## 지원 범위

현재 macOS amd64와 arm64 아카이브를 제공합니다. Apple 코드 서명과 공증은 제공하지 않습니다.

이 저장소는 공개 릴리스 배포 전용입니다. 소스 코드와 Issue 관리는 공개하지 않습니다.
